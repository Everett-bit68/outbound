Outbound

Outbound is a web-based outdoor activity planner that helps users understand current weather conditions and decide when to go outside. It uses weather and air-quality data from Open-Meteo APIs to provide forecasts, environmental information, and activity recommendations.

Features

Location Detection: Attempts to retrieve local weather using your browser's location.

City Search: Search for a city to view its weather information.

Current Weather: View temperature and a simplified weather condition.

Weather Forecasts: Explore hourly and three-day forecasts.

Environmental Information: Check the UV index and PM2.5 air-quality readings.

Outside Score: View a score out of 100 based on precipitation, temperature, and wind speed.

Activity Recommendations: Get suitability suggestions for jogging, cycling, park walks, and photography.

Activity Advice: Explore guidance for running, cycling, outdoor dining, and photography.

Dark Mode: Switch between light and dark themes, with the selected theme saved in your browser.

Getting Started

Prerequisites

A modern web browser

An active internet connection

Installation and Usage

Download or clone this project.

Ensure index.html, style.css, and app.js are in the same folder.

Open index.html in your browser.

Allow location access when prompted, or enter a city name in the search box.

Explore the weather information, forecasts, Outside Score, and activity recommendations.

Toggle dark mode to test the appearance.

If location access is unavailable, the application uses Singapore as its default location.

Notes and Limitations

Weather information depends on the availability of the Open-Meteo APIs.

Activity recommendations and the Outside Score use simplified, rule-based calculations and should not replace official weather warnings or personal safety judgment.

The Share Weather button is displayed but is not yet functional.

This is a front-end project and does not require a backend or database.
