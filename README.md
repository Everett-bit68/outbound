Outbound - outdoor activity tracker
Outbound is a real-time outdoor activity planner and weather dashboard built with Vanilla JavaScript and the Open-Meteo API.
It features dynamic activity suitability filters, air quality metrics, and intelligent hourly window analysis to help users find the optimal time to step outside.

How it was built
This project is made entirely with javascript, CSS and html.

How to run it
First download this repository anywhere in ur computer.
Then open index.html in visual studio code (or ur desired editor) and then u can start using it normally.
